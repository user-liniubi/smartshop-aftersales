# SmartShop AI 本地启动与部署说明

## 本地开发

```powershell
uv python install 3.11
uv sync
Copy-Item .env.example .env
docker compose up -d mysql redis
uv run alembic upgrade head
uv run python -m sample_data.seed
uv run python -m scripts.ingest_demo_docs
uv run uvicorn backend.app.main:app --reload
```

消费者端和客服端：

```powershell
uv run streamlit run frontend/consumer_app.py --server.port 8501
uv run streamlit run frontend/agent_app.py --server.port 8502
```

异步 Worker：

```powershell
uv run celery -A backend.app.workers.celery_app:celery_app worker --loglevel=INFO --pool=solo -Q knowledge
```

## Docker Compose

```powershell
Copy-Item .env.example .env
docker compose up --build
```

服务：

- API `http://127.0.0.1:8000`
- 消费者端 `http://127.0.0.1:8501`
- 客服端 `http://127.0.0.1:8502`
- MySQL `127.0.0.1:3308`
- Redis `127.0.0.1:6381`

初始化服务自动执行迁移、演示数据和知识索引。BGE 在启动阶段预热，避免首个用户请求承担冷启动耗时。

## 安全检查

- `.env`、上传目录、Chroma、日志和临时文件不进入 Git/Docker context；
- AUTH_SECRET 必须替换；
- 不在日志和文档中写入 API Key；
- 模拟退款不连接真实支付。
