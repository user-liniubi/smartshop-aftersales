# SmartShop AI 退款授权决策机制说明

## 数据

- `refund_authorization_rules`：场景、金额上下限、版本和状态；
- `agent_decisions`：建议金额、置信度、证据和后端校验；
- `after_sales_tickets`：最终审批金额和状态；
- `refund_executions`：模拟退款执行、幂等键、重试和流水。

## 自动审批条件

- 订单资格通过；
- 场景存在且启用；
- 金额在授权范围；
- 金额不超过可退余额；
- 金额大于零；
- 置信度不低于 0.80；
- 有政策证据；
- 无重复活动申请。

任何条件失败都进入人工审核。

## 人工审批

客服可以调整最终金额，但后端再次检查：

- 正数；
- 不超过剩余可退余额；
- 写入工单；
- 更新 Agent 决策为 `manually_approved`。

## 审批与执行

```text
审批通过
→ 固定幂等键
→ pending 执行记录
→ 模拟退款网关
→ success / failed
→ 失败最多重试 3 次
```

重复执行不会产生第二笔退款。当前网关为模拟实现，不产生真实资金交易。
