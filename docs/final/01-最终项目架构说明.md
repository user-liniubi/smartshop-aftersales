# SmartShop AI 最终项目架构说明

## 定位

SmartShop AI 是单商家消费电子客服系统，覆盖售前咨询、订单履约和售后服务。它不是商城、支付系统或多商家 SaaS。

## 分层

```text
消费者端 / 客服端
        ↓
FastAPI 认证、角色与对象权限
        ↓
统一业务工作流
  ├─ 售前：商品、参数、价格、库存、优惠
  ├─ 履约：本人订单、多订单、物流、售后进度
  └─ 售后：退、换、修、补偿、政策、故障排查
        ↓
DeepSeek 意图/槽位/解释
BGE + Chroma 分类知识检索
MySQL 白名单业务工具
后端确定性规则与状态机
        ↓
回答 / 工单 / 人工接管 / 审批 / 模拟执行
```

## 权威边界

- 用户身份来自认证上下文；
- 订单、物流、价格、库存来自 MySQL；
- 售后期限、资格和可退余额由代码计算；
- RAG 只提供商品说明、政策与 SOP；
- Agent 只做有限判断，不直接查 SQL、不直接退款、不改配置；
- 后端正则和事务负责最终业务结果。

## 基础设施

- FastAPI + Pydantic + SQLAlchemy 2；
- MySQL 8、Redis、Celery；
- BGE、Chroma、DeepSeek；
- Streamlit 双端；
- Docker Compose 一键部署；
- Pytest、Ruff、固定评测集。

详细部署和源码入口见项目 README 与 `docs/final/09-本地启动与部署说明.md`。
