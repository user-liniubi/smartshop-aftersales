# SmartShop AI 业务流程说明

## 售前

```text
商品问题
→ 商品工具查询实例事实
→ 商品知识 RAG
→ 需要优惠时读取商家授权
→ 后端计算模拟报价
→ 超额转人工
```

价格和库存来自数据库；商品介绍、使用说明和优惠政策来自 RAG。

## 履约

```text
订单指代
→ 服务端按认证用户解析候选
→ 单候选自动确认
→ 多候选要求选择
→ 查询订单/物流/售后进度
→ 回答或转人工
```

模型不能传入 `user_id`，也不能通过 RAG 查询实时订单。

## 售后

```text
售后诉求
→ 订单和商品核验
→ 政策检索
→ 确定性资格与期限
→ 信息不足则追问
→ 普通申请创建待审批工单
→ 部分补偿进入授权判断
→ 人工或授权内自动审批
→ 退款执行服务
```

## 人工接管

AI 失败、证据不足、疑似人为损坏、超额优惠或退款时创建 handoff。客服原子接管后，`control_version` 阻止旧 AI 任务继续写消息或创建工单。

## 状态隔离

- 会话状态：open / need_human / human_active / closed；
- 工作流状态：收集、选订单、查订单、查政策、回答、人工；
- 工单状态：待审批、通过、拒绝、取消；
- 退款执行状态：pending / success / failed。
