# SmartShop AI Agent 工作流说明

## Agent 做什么

- 识别统一意图；
- 提取订单号、问题描述和提交意图；
- 在有限工具白名单中选择业务工具；
- 在商家授权范围内提出补偿建议；
- 基于已验证事实和政策生成解释。

## Agent 不做什么

- 不决定当前用户；
- 不执行任意 SQL；
- 不计算售后期限或可退余额；
- 不修改商品、优惠和退款授权；
- 不直接发起真实退款；
- 不进行多 Agent 自主规划。

## 调用顺序

```text
保存用户消息
→ 检查会话状态
→ DeepSeek 意图与槽位
→ 后端合并槽位和订单候选
→ 状态机选择子流程
→ Tool / RAG
→ 确定性规则
→ 有限 Agent 判断
→ 后端校验
→ 回答、建单或人工
```

## 受控示例

退款补偿：

```text
资格由代码判定
→ DeepSeek 在给定规则内提出金额和置信度
→ 后端检查场景、范围、余额、正数、证据和置信度
→ 全部通过才自动审批
```

售前优惠：

```text
DeepSeek 识别优惠咨询
→ 商品工具确认商品
→ RAG 确认政策
→ 后端按优惠规则计算金额
→ 超限转人工
```
